# 시험지 넣는 곳

기출 분석 팀은 매일 밤 이 폴더의 PDF 를 가져가 문항을 옮기고 분류합니다.

- **시험지 PDF 와 정답표 PDF 를 함께** 넣어 주세요. (정답표가 없으면 정답 칸이 비어요)
- 넣는 방법: GitHub 에서 이 폴더(`inbox/`)를 열고 **Add file → Upload files** 로 끌어다 놓은 뒤 Commit.
- 파일 이름은 자유지만, 알아보기 쉽게 써 주면 접수가 정확해져요. 예: `2022-09-고1-학평-수학.pdf`, `2022-09-고1-학평-수학-정답.pdf`
- 평가원·교육청이 공개한 PDF 만 넣어 주세요. (수식이 글자로 들어 있는 원본 PDF 일수록 옮김이 정확해요)
- 처리된 시험지는 `analysis-team/queue.json` 에서 `done` 으로 바뀌고, PDF 는 그대로 남겨 둡니다.
