# 설계 요약

## 결정사항

| 항목 | 결정 |
| --- | --- |
| 대상 | 고등학교 (중학교는 추후) |
| 수록 범위 | 수능, 평가원 모의평가, 교육청 학력평가 · 최근 10년 |
| 분류 | 학년이 아닌 과목 → 단원 → 성취기준. 풀이에 필요한 가장 위 과목에 배정 (`site/data/math/curriculum.json`의 level) |
| 교육과정 외 | 빼지 않고 `교육과정 외` 태그 |
| 태그 | 성취기준 코드 + 짧은 개념명 |
| 검색 | 과목, 단원, 배점, 정답률, 연도 범위, 시행기관 |
| 정답률 | 공식 발표가 없어 관리자가 출처와 함께 입력하는 선택 항목 |
| 출력 | 2단 HWPX, 한 쪽 4문항, 풀이 공간, 문항별 출처, 정답표 |
| 댓글 | 익명 (로그인 방식으로 바꿀 수 있게 설계) · 관리자는 웹 안에서 알림 확인 |
| 관리자 | 운영자가 지정 · PDF/한글 원본 업로드 → AI 분석(관리자 API 키) → 검수 후 승인 |
| 운영비 | 무료 범위 (GitHub, Cloudflare) |
| 디자인 | HSOrbit 톤 (종이·먹·주황 바늘), 데스크톱 우선 |

## 구 교육과정 매핑

| 시험 시기 | 적용 교육과정 |
| --- | --- |
| 2028학년도 수능~ | 2022 개정 |
| 2022~2027학년도 수능 | 2015 개정 (공통 수학I·II + 선택 미적분·확통·기하) |
| 2017~2021학년도 수능 | 2009 개정 (가형·나형) |

## 단계

1. **지금**: 문항 데이터 형식, 한글 시험지 엔진, 검색·다운로드 화면, 자동 빌드
2. 다음: 관리자 화면 (PDF 업로드 → 문항 자르기 → AI 분류 → 검수 → GitHub 커밋)
3. 다음: 익명 댓글·관리자 알림 (Cloudflare Workers + D1 + Turnstile)
4. 다음: 2015·2009 개정 → 2022 개정 매핑표, 기출 대량 입력
